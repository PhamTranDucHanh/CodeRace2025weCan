# Project Documentation Folder

This folder contains all documentation and supporting materials for the project. The project began with ideation and experimentation, evolving through multiple stages and upgrades. After the CodeRace2025 competition, the system was further enhanced with a new microcontroller (ESP32), the ESP-IDF framework, and an RTOS-based architecture.

**Folder structure:**

- `/requirements`: Contains the original problem statements and requirements from the CodeRace2025 organizers.
- `/reports`: Includes all reports, presentations, and slides from each development phase and upgrade.
- `/images`: Stores important images and diagrams related to the project.

Further details about the post-competition upgrades (ESP32, IDF, RTOS) can be found in the `README.md` inside the `/src` directory.
